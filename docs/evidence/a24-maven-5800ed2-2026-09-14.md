# Maven installation of the integrated 0.2 candidate

A user should be able to install the intended library, run a database check,
and repeat it from a prepared cache without contacting external repositories.
A wrong download, unexpected repository or mixed runtime must produce the
intended rejection rather than an unrelated green build.

The existing Maven A-24 matrix passed on producer
`5800ed2960aefbf63c01d2ebaf2265278d662494`, using consumer
`efcfbb4ca30ad8dd1531f97c654068c36bb8410a` with identical production/publication
inputs. See the [minimized receipt](a24-maven-5800ed2-2026-09-14.json).

| --- | --- | --- | --- |
| Java 17 | 5.5.2 | 3 / 3 passed | 4 passed |
| Java 17 | 5.5.3 | 3 / 3 passed | 4 passed |
| Java 21 | 5.5.2 | 3 / 3 passed | 4 passed |
| Java 21 | 5.5.3 | 3 / 3 passed | 4 passed |

All 24 MySQL executions passed without failures, errors or skips. Each cell
also verified rejection of a modified checksum, an unexpected repository,
a wrong runtime anchor and a wrong non-anchor component. The business row
stayed the same when physical execution expanded from one attempt to two;
both CLI report formats returned the expected regression result.

Offline phases used a disposable copy of their own immutable primed cache.
The prime HTTP repository was stopped and connection refusal was checked.
An operating-system rule denied external network access while allowing
loopback and the local Docker socket. Actual Java 17/21 network probes,
unchanged local container images and private-home checks were retained.

A read-only audit checked eight original JUnit XML reports, 128 negative-control
file hashes, 40 consumer class files, 32 first-party payload copies, 14 fixture
inputs and nine candidate receipt artifacts. Java 17 consumers compiled to major
61; Java 21 consumers compiled to major 65. These are consumer class versions,
not a change to the published library's Java target.

Environment: Maven 3.9.14, Temurin 17.0.20.1+1, Homebrew OpenJDK 21.0.11,
macOS arm64, and digest-pinned MySQL 8.4.11.
Evidence labels: **verified - MySQL**, **verified - ShardingSphere-JDBC 5.5.2**,
**verified - ShardingSphere-JDBC 5.5.3**.
